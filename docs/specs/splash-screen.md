# 스플래시 화면 스펙

## 스펙

- 앱 최초 진입 시 스플래시 화면을 먼저 표시한다.
- 스플래시 화면은 TODO 상태이므로 아무 UI도 표시하지 않는 빈 화면으로 둔다.
- 스플래시 화면은 카메라, 마이크, 위치, 사진 저장 권한의 허용 여부를 확인한다.
- 스플래시 화면은 필수 권한 보유 여부에 따라 다음 화면을 결정한다.
- 필수 권한이 모두 허용되어 있으면 카메라 화면으로 이동한다.
- 필수 권한 중 하나라도 허용되어 있지 않으면 권한 화면으로 이동한다.

## 정책

- 위치는 정확한 위치 또는 대략적인 위치 중 하나라도 허용되면 위치 권한이 있는 것으로 본다.
- Android 33+에서 앱이 직접 생성한 사진을 공유 저장소에 저장하는 경우에는 런타임 사진 저장 권한을 별도로 요구하지 않는 것으로 본다.
