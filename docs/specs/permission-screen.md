# 권한 화면 스펙

## 스펙

- 권한 화면은 앱 사용에 필요한 권한을 사용자가 확인하고 요청할 수 있는 화면이다.
- 권한 화면에 표시하는 권한은 `Camera`, `Microphone`, `Location`, `Save Photos`이다.
- 권한 화면은 각 권한 항목에 제목, 설명, 권한 상태를 표시한다.
- 권한 화면은 권한이 허용된 항목을 체크된 상태와 `Allowed` 상태 텍스트로 표시한다.
- 권한 화면은 권한이 허용되지 않은 항목을 체크되지 않은 상태와 `Required` 상태 텍스트로 표시한다.
- 사용자가 허용되지 않은 권한 항목을 선택하면 해당 권한 요청 절차를 시작한다.
- 사용자가 허용된 권한 항목을 선택해도 중복 권한 요청 절차를 시작하지 않는다.
- 권한 화면은 `Open app settings` 버튼을 표시한다.
- 사용자가 `Open app settings` 버튼을 선택하면 앱 설정 화면으로 이동한다.
- 카메라, 마이크, 위치, 사진 저장 권한이 모두 허용되면 카메라 화면으로 이동한다.

## 정책

- 사진 저장 항목은 촬영 결과를 기기 사진 라이브러리에 저장할 수 있음을 안내하는 항목이다.
- 위치 권한은 정확한 위치 또는 대략적인 위치 중 하나라도 허용되면 충족된 것으로 본다.
- Android 33+에서는 앱이 직접 생성한 사진이나 동영상을 공유 저장소에 저장할 때 별도 사진 저장 런타임 권한을 요구하지 않는다.
- iOS에서는 사진 라이브러리에 항목을 추가하기 위한 권한을 요청한다.
- 앱 설정 버튼은 사용자가 시스템 권한 대화상자에서 권한을 변경할 수 없는 경우에도 직접 권한을 변경할 수 있는 대체 경로다.
