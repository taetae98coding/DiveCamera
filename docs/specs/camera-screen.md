# 카메라 화면 스펙

## 스펙

- 카메라 화면 진입 시 ViewFinder 영역을 화면 가운데 표시한다.
- ViewFinder는 화면 좌우 가장자리까지 확장한다.
- ViewFinder는 사진 캡처 모드의 세로 화면에서 3:4 비율로 표시한다.
- ViewFinder는 `VIDEO` 캡처 모드의 세로 화면에서 비디오 저장 결과와 같은 9:16 비율로 표시한다.
- ViewFinder는 기기의 카메라 미리보기를 표시한다.
- 카메라 미리보기는 ViewFinder 영역을 채워 표시한다.
- 카메라 미리보기는 ViewFinder 영역 밖에 표시되지 않는다.
- 카메라 화면은 화면 하단 가운데에 사진 촬영 버튼을 표시한다.
- 카메라 화면은 사진 촬영 버튼 왼쪽에 캡처 모드 전환 버튼을 표시한다.
- 카메라 화면은 카메라 미리보기 위쪽에 촬영 정보 오버레이를 표시한다.
- 촬영 정보 오버레이는 ISO 감도, 조리개 F값, 셔터 스피드, 노출 보정 EV값, 렌즈 초점거리 mm를 표시한다.
- 촬영 정보 오버레이의 조리개 F값은 숫자 앞에 `F`를 붙여 표시한다.
- 현재 캡처 모드가 `VIDEO`이면 촬영 정보 오버레이는 ISO 감도, 조리개 F값, 셔터 스피드 표시 영역에 비디오 촬영 시간을 표시한다.
- 비디오 촬영 시간은 녹화 전에는 `00:00`으로 표시한다.
- 비디오 촬영 시간은 녹화 중에는 현재 녹화 경과 시간으로 갱신한다.
- 촬영 정보 오버레이의 `ISO` 표시 영역은 사용자가 선택할 수 있는 버튼이다.
- 촬영 정보 오버레이의 `F` 표시 영역은 사용자가 선택할 수 있는 버튼이다.
- 촬영 정보 오버레이의 `S` 표시 영역은 사용자가 선택할 수 있는 버튼이다.
- 사용자가 `ISO`, `F`, `S`, `EV` 표시 영역 중 하나를 선택하면 노출 설정 Dialog를 표시한다.
- 노출 설정 Dialog는 `Auto Mode`와 `Manual Mode`를 선택할 수 있다.
- 노출 설정 Dialog에서 `Auto Mode`를 선택하면 EV값을 수정할 수 있다.
- 노출 설정 Dialog에서 `Manual Mode`를 선택하면 ISO 감도와 셔터 스피드를 수정할 수 있다.
- 현재 캡처 모드가 `VIDEO`이면 노출 설정 Dialog는 `Auto Mode`만 선택할 수 있다.
- 현재 캡처 모드가 `VIDEO`이면 노출 설정 Dialog에서 EV값을 수정할 수 있다.
- 현재 캡처 모드가 `VIDEO`이면 카메라 화면은 `Manual Mode`를 적용하지 않는다.
- 노출 설정 Dialog의 `Manual Mode`에서 ISO 감도는 `100`, `125`, `160`, `200`, `250`, `320`, `400`, `500`, `640`, `800`, `1000`, `1250`, `1600`, `2000`, `2500`, `3200`, `4000` 단계로 변경할 수 있다.
- 노출 설정 Dialog의 `Manual Mode`에서 셔터 스피드는 `1/250s`, `1/200s`, `1/160s`, `1/125s`, `1/100s`, `1/80s`, `1/60s`, `1/50s`, `1/40s`, `1/30s` 단계로 변경할 수 있다.
- 노출 설정 Dialog가 열린 상태에서 촬영 정보가 갱신되어도 Dialog에서 사용자가 선택 중인 값은 유지된다.
- 노출 설정 Dialog에서 적용을 선택하면 카메라 화면은 선택한 노출 모드와 노출 값을 적용한다.
- 노출 설정 Dialog 바깥 영역을 선택하면 노출 설정 Dialog를 닫는다.
- 현재 노출 모드가 `Manual Mode`이면 촬영 정보 오버레이는 `EV` 표시 영역을 숨긴다.
- 현재 노출 모드가 `Manual Mode`이면 촬영 정보 오버레이의 둘째 줄에는 `LENS` 표시 영역만 표시한다.
- 현재 캡처 모드가 `VIDEO`이면 촬영 정보 오버레이는 노출 모드를 `Auto Mode`로 표시한다.
- 촬영 정보 오버레이의 `EV` 표시 영역은 사용자가 선택할 수 있는 버튼이다.
- 촬영 정보 오버레이의 렌즈 초점거리 mm는 플랫폼 갤러리 앱의 표시와 맞도록 35mm 환산 초점거리를 우선 표시한다.
- 35mm 환산 초점거리를 확인할 수 없으면 촬영 정보 오버레이의 렌즈 초점거리 mm는 물리 초점거리를 표시한다.
- 촬영 정보 오버레이의 `LENS` 표시 영역은 사용자가 선택할 수 있는 버튼이다.
- 카메라 화면은 최초 확인한 지원 렌즈 목록의 첫 번째 렌즈를 기본 렌즈로 선택한다.
- 지원 렌즈 목록은 전면과 후면 방향을 구분하지 않고 플랫폼이 앱에 제공하는 렌즈를 포함한다.
- 지원 렌즈 목록은 iOS TrueDepth 카메라를 포함하지 않는다.
- 지원 렌즈 목록은 Android 얼굴 인식용 IR 또는 보안 카메라를 포함하지 않는다.
- 사용자가 `LENS` 표시 영역을 선택하면 카메라 화면은 최초 확인한 지원 렌즈 목록의 다음 index 렌즈로 전환한다.
- 마지막 index 렌즈에서 사용자가 `LENS` 표시 영역을 선택하면 카메라 화면은 최초 확인한 지원 렌즈 목록의 첫 번째 렌즈로 전환한다.
- 지원하는 렌즈가 없거나 하나뿐이면 사용자가 `LENS` 표시 영역을 선택해도 현재 렌즈를 유지한다.
- 렌즈 전환 후 카메라 미리보기와 사진 촬영은 전환된 렌즈를 사용한다.
- 렌즈 전환 후 새 카메라 세션이 사진 촬영 준비를 완료하면 사진 촬영 버튼은 `Ready` 상태로 돌아온다.
- 전면 카메라 촬영 결과는 카메라 미리보기와 같은 좌우 방향으로 저장한다.
- 촬영 정보 오버레이에서 플랫폼이 확인할 수 없는 항목은 `--`로 표시한다.
- 사진 촬영 버튼 상태는 `Busy`, `Ready`로 구분한다.
- 카메라 화면 최초 진입 후 카메라가 사진 촬영 준비를 완료하기 전까지 사진 촬영 버튼은 `Busy` 상태이다.
- 사진 촬영 요청 후 사진 저장과 메타데이터 후처리가 완료되어 다음 사진 촬영 준비가 완료되기 전까지 사진 촬영 버튼은 `Busy` 상태이다.
- 사진 촬영 버튼이 `Busy` 상태이면 로딩 UI를 표시한다.
- 사진 촬영 버튼이 `Busy` 상태이면 사용자가 선택해도 사진 촬영 요청을 시작하지 않는다.
- 사진 촬영 버튼이 `Ready` 상태이면 사용자가 선택할 때 현재 캡처 모드로 카메라 사진 촬영을 요청할 수 있다.
- 카메라 화면의 기본 캡처 모드는 `JPG`이다.
- 캡처 모드 전환 버튼은 현재 캡처 모드를 표시한다.
- 사용자가 캡처 모드 전환 버튼을 선택하면 현재 캡처 모드는 `JPG`, `RAW`, `RAW+JPG`, `VIDEO` 순서로 반복 변경된다.
- 캡처 모드 전환 버튼은 `RAW+JPG` 모드를 `RAW`와 `JPG`가 줄바꿈된 두 줄 텍스트로 표시한다.
- 현재 캡처 모드가 `RAW` 또는 `RAW+JPG`이고 RAW 사진 촬영 지원 여부 확인이 완료된 뒤 기기가 RAW 사진 촬영을 지원하지 않는 것으로 확인되면 캡처 모드 전환 버튼의 우측 상단에 작은 노란색 주의 아이콘을 표시한다.
- `Ready` 상태의 사진 촬영 버튼을 누르면 현재 캡처 모드로 카메라 사진을 촬영한다.
- 현재 캡처 모드가 `VIDEO`이고 비디오 녹화 중이 아니면 `Ready` 상태의 사진 촬영 버튼을 누를 때 비디오 녹화를 시작한다.
- 현재 캡처 모드가 `VIDEO`이고 비디오 녹화 중이면 사진 촬영 버튼을 누를 때 비디오 녹화를 중지한다.
- 비디오 녹화 중에는 캡처 모드 전환 버튼을 선택해도 현재 캡처 모드를 유지한다.
- 비디오 녹화 중에는 사용자가 `LENS` 표시 영역을 선택해도 현재 렌즈를 유지한다.
- 비디오 녹화 중에는 마지막 사용자 입력 후 30초가 지나도 카메라 미리보기 리소스를 반납하지 않는다.
- 촬영 결과는 현재 캡처 모드와 플랫폼 정책에 따라 기기의 기본 갤러리 앱에서 볼 수 있도록 저장한다.
- 촬영 결과는 플랫폼이 해당 출력 포맷에서 제공하는 프레임, 해상도, 후처리 결과를 따른다.
- 촬영 결과는 플랫폼이 제공하는 촬영 메타데이터를 가능한 범위에서 보존한다.
- 촬영 결과는 앱이 확인할 수 있는 카메라와 렌즈 메타데이터를 가능한 범위에서 추가 기록한다.
- Android RAW 촬영 결과는 앱이 확인할 수 있는 실제 촬영 프레임의 ISO 감도, 조리개 F값, 셔터 스피드를 가능한 범위에서 포함한다.
- 사진과 비디오 촬영 결과는 앱이 확인할 수 있는 촬영 위치를 GPS 메타데이터로 저장한다.
- 촬영 위치를 확인할 수 없으면 촬영 결과 저장은 실패하지 않는다.
- 특정 출력 포맷이 플랫폼 메타데이터 후처리 쓰기 저장을 지원하지 않으면 해당 포맷의 후처리는 생략하고 사진 저장 성공으로 처리한다.
- 촬영 결과 저장, 사진 라이브러리 등록, 메타데이터 기록 후처리가 실패하면 플랫폼이 전달한 오류 메시지를 그대로 Snackbar로 표시한다.
- 카메라 화면이 표시되는 동안 기기의 화면 자동 꺼짐을 방지한다.
- 마지막 사용자 입력 후 30초가 지나면 카메라 미리보기 리소스를 반납한다.
- 카메라 미리보기 리소스를 반납한 상태에서는 ViewFinder 영역을 표시하지 않는다.
- 카메라 미리보기 리소스를 반납한 상태에서는 사진 촬영 버튼을 표시하지 않는다.
- 카메라 미리보기 리소스를 반납한 상태에서는 캡처 모드 전환 버튼을 표시하지 않는다.
- 카메라 미리보기 리소스를 반납한 상태에서는 촬영 정보 오버레이를 표시하지 않는다.
- 카메라 미리보기 리소스를 반납한 상태에서는 `Camera Off` 텍스트를 표시한다.
- 카메라 미리보기 리소스를 반납한 상태에서 사용자가 입력하면 ViewFinder 영역, 카메라 미리보기, 사진 촬영 버튼, 캡처 모드 전환 버튼, 촬영 정보 오버레이를 다시 표시한다.

## 정책

- 카메라 화면의 촬영 정보는 플랫폼이 제공하는 현재 값 또는 최신 확인 값을 표시한다.
- 카메라 화면의 촬영 정보는 플랫폼이 제공하지 않는 값을 앱이 임의로 생성해 보장하지 않는다.

## 캡처 모드 정책

- `JPG` 모드는 플랫폼의 처리 사진 출력으로 저장한다.
- iOS `JPG` 모드는 `Auto Mode`에서 사진 품질을 우선하여 저장한다.
- iOS `JPG` 모드는 `Manual Mode`에서 사진 품질과 촬영 속도의 균형을 우선하여 저장한다.
- `RAW` 모드는 플랫폼이 RAW DNG 출력을 지원하는 경우 RAW DNG로 저장한다.
- `RAW` 모드에서 플랫폼이 RAW DNG 출력을 지원하지 않으면 `JPG` 모드의 처리 사진 출력 정책으로 저장한다.
- `RAW+JPG` 모드는 플랫폼이 RAW DNG와 처리 사진의 페어 출력을 지원하는 경우 RAW DNG와 처리 사진을 함께 저장한다.
- `RAW+JPG` 모드에서 플랫폼이 RAW DNG 출력을 지원하지 않으면 `JPG` 모드의 처리 사진 출력 정책으로 저장한다.
- `RAW` 또는 `RAW+JPG` 모드에서 플랫폼이 RAW DNG 출력을 지원하지 않으면 캡처 모드 전환 버튼에 RAW 미지원 주의 아이콘을 표시한다.
- `RAW` 모드는 RAW DNG와 처리 사진을 동시에 저장하는 RAW+JPG 페어 저장을 보장하지 않는다.
- `RAW+JPG` 모드는 RAW DNG와 처리 사진의 해상도, 픽셀 단위 프레이밍, 압축, 후처리 결과가 완전히 동일함을 보장하지 않는다.
- `JPG`, `RAW`, `RAW+JPG` 모두 카메라 미리보기와 저장 결과의 해상도, 픽셀 단위 프레이밍, 압축, 후처리 결과가 완전히 동일함을 보장하지 않는다.
- `JPG`, `RAW`, `RAW+JPG` 모두 플랫폼이 제공하지 않는 메타데이터 값을 앱이 임의로 생성해 보장하지 않는다.
- `VIDEO` 모드는 플랫폼의 처리 비디오 출력으로 저장한다.
- `VIDEO` 모드는 오디오를 포함해 저장한다.
- `VIDEO` 모드는 기본으로 4K UHD 해상도와 60fps 촬영을 요청한다.
- `VIDEO` 모드는 현재 기기, 렌즈, 플랫폼 카메라 파이프라인이 4K UHD 또는 60fps 촬영을 지원하지 않으면 플랫폼이 선택할 수 있는 지원 해상도 또는 프레임레이트로 저장한다.
- `VIDEO` 모드는 현재 기기, 렌즈, 플랫폼 카메라 파이프라인이 HDR 비디오 촬영을 지원하면 HDR 비디오 촬영을 요청한다.
- `VIDEO` 모드는 HDR 비디오 촬영을 지원하지 않는 환경에서는 SDR 비디오로 저장한다.
- `VIDEO` 모드는 현재 기기, 렌즈, 플랫폼 카메라 파이프라인이 지원하는 범위에서 녹화 비디오 손떨림 보정을 최대 수준으로 요청한다.
- `VIDEO` 모드는 비디오 손떨림 보정을 지원하지 않는 환경에서도 비디오 저장을 실패하지 않는다.
