# 화면 이동 (Navigation) — 요구사항

> 기획자 관점에서 원하는 동작을 기술한다. 코드/플랫폼 구분은 다루지 않는다.
>
> 이 문서는 **화면 사이의 이동(라우팅)** 만 다룬다. 각 화면 내부의 구성과 동작은 해당 주제 문서를 참조한다.
> - 권한 요청 화면: [권한 요구사항](permission.md)
> - 홈 화면: [홈 요구사항](home.md)

## 개요

앱은 **권한 요청(Permission)** 화면과 **홈(Home)** 화면을 가진다. 앱을 실행했을 때 사용자의 권한 상태에 따라 알맞은 화면으로 자동으로 안내하고, 권한 화면에서 시작하면 홈으로 이동해 본격적인 사용을 시작할 수 있게 한다.

## 화면

| 화면 | 역할 |
| --- | --- |
| 권한 요청(Permission) | 앱에 필요한 권한을 안내하고 요청한다. |
| 홈(Home) | 권한이 준비된 뒤 진입하는 메인 화면. |

## 동작

### 앱 실행 시 시작 화면 결정

앱을 실행하면 권한 상태를 확인해 시작 화면을 자동으로 결정한다.

- **4개 권한(카메라·마이크·사진 저장·위치)이 모두 허용**되어 있으면 → 곧바로 **홈** 화면으로 진입한다.
- **하나라도 허용되지 않은 권한이 있으면** → **권한 요청** 화면으로 진입한다.

### 권한 요청 화면에서 홈으로 이동

- 권한 요청 화면에서 사용자는 홈 화면으로 이동할 수 있다. (이동을 시작하는 버튼의 문구·활성 조건 등 세부는 [권한 요구사항](permission.md) 참조)
- 권한 요청 화면에 있는 동안 **4개 권한이 모두 허용되면 별도 조작 없이 자동으로 홈으로 이동**한다.
- 홈으로 이동하면 권한 요청 화면으로는 **뒤로 가기로 돌아가지 않는다.** (홈에서 뒤로 가기를 하면 앱을 빠져나간다.)
