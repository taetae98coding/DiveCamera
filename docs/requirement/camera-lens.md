# 렌즈 선택 (Camera Lens) — 요구사항

> 기획자 관점에서 원하는 동작을 기술한다. 코드/플랫폼 구분은 다루지 않는다.
>
> 이 문서는 현재 렌즈의 초점거리를 **읽어서 보여 주는** [노출 정보 표시 요구사항](camera-exposure.md) 위에 얹히는, 사용자가 **렌즈 자체를 직접 골라 바꾸는** 기능을 다룬다. 설정 오버레이의 구성·진입·제스처·절전 연동은 [수동 노출 제어 요구사항](camera-exposure-control.md)을 따르며, 이 문서는 그 오버레이가 예고해 둔 "렌즈 선택" 항목의 실제 동작을 정의한다.

## 개요

요즘 카메라 기기는 **초광각·광각·망원** 처럼 화각이 다른 여러 렌즈를 함께 가지며, **후면 렌즈들과 전면(셀카) 렌즈**를 모두 갖는다. 이 기능은 사용자가 카메라 화면에서 **기기가 가진 렌즈 중 하나를 직접 골라 전환**할 수 있게 한다. 선택은 화면 상단 촬영 정보 영역을 눌러 여는 **설정 오버레이**에서 한다.

지금까지는 기기가 정한 기본 렌즈로만 미리보기가 동작했다. 이 단계에서 사용자는 **광각으로 넓게 담거나, 초광각으로 더 넓게, 망원으로 멀리 당기거나, 전면(셀카) 렌즈로 전환**하도록 렌즈를 바꿀 수 있다.

렌즈는 **후면(Back) / 전면(Front)** 으로 나뉘므로, 목록의 각 렌즈가 후면인지 전면인지 함께 보여 준다.

## 진입과 화면 구성

- 설정 오버레이를 여는 방법(상단 정보 영역 탭 / 스와이프)과 리스트의 기본 구성은 [수동 노출 제어 요구사항](camera-exposure-control.md)을 그대로 따른다.
- 설정 오버레이 리스트의 **노출 항목들 아래에 "Lens" 항목**을 둔다. (노출 제어 요구사항이 "향후 추가"로 예고한 렌즈 선택 항목이다.)
- **"Lens" 항목**은 **현재 사용 중인 렌즈의 초점거리**를 함께 보여 주고, 누르면 **기기가 지원하는 렌즈 목록**이 리스트로 펼쳐진다.
- 펼쳐진 목록은 각 렌즈를 **후면/전면 구분과 풀프레임(35mm) 환산 초점거리**로 보여 주고, **현재 사용 중인 렌즈에는 표시(체크)** 가 붙는다. 목록은 현재 렌즈가 보이도록 열린다.
- 목록은 **후면 렌즈를 먼저, 전면(셀카) 렌즈를 뒤에** 보여 주고, 같은 면 안에서는 초점거리 순으로 정렬한다.
- 목록에서 렌즈 하나를 고르면 그 렌즈로 전환된 뒤 항목 리스트로 돌아온다.

## 동작

- 렌즈를 고르면 **미리보기가 그 렌즈의 화면으로 즉시 전환**되고, 상단 촬영 정보의 **초점거리 표시도 새 렌즈 값으로 갱신**된다. 후면↔전면 전환도 같은 방식으로 즉시 반영된다.
- 렌즈를 바꿔도 **현재 촬영 모드(P / Manual)는 유지**된다. 노출 값은 새 렌즈 기준으로 다시 잡힌다.
- **기기가 고를 수 있는 렌즈가 하나뿐이거나 없으면** "Lens" 항목은 **비활성으로 보여 들어갈 수 없다.** (노출 제어에서 선택지가 하나뿐인 항목을 비활성으로 두는 것과 같다.)
- **현재 렌즈의 초점거리는 어디서 보든 같은 값**이어야 한다. 즉 상단 촬영 정보의 초점거리, "Lens" 항목이 보여 주는 현재 값, 렌즈 목록에서 현재 렌즈(체크된 행)의 값이 **서로 일치**한다.

## 표기

- 각 렌즈와 "Lens" 항목의 현재 값은 **풀프레임(35mm) 환산 초점거리**로 표기하며, 표기 형식은 [노출 정보 표시 요구사항](camera-exposure.md)의 초점거리 표기(예: `13mm`(초광각), `26mm`, `77mm`)를 그대로 따른다.
- 렌즈 목록의 각 행에는 초점거리와 함께 **후면(Back) / 전면(Front)** 구분을 보여 준다.
- 초점거리를 알 수 없는 렌즈는 초점거리 부분을 `--` 로 표시한다.

## 제스처 / 절전 / 유지 범위

- 오버레이의 **제스처 조작**(스와이프 커서 이동, 볼륨 키 선택, 탭)과 **절전 연동**은 [수동 노출 제어 요구사항](camera-exposure-control.md)을 그대로 따른다. 렌즈 선택 항목·목록도 같은 리스트 위에서 같은 방식으로 조작한다.
- 한 번 고른 렌즈는 **카메라가 켜져 있는 동안만 유지**되며, 앱을 다시 켜면 기본 렌즈로 초기화된다. (영구 저장은 범위 밖 — 노출 제어와 동일.)

## 범위 밖 (이번 단계 제외)

- **연속 줌(배율 슬라이더)**: 이 단계는 기기가 가진 **개별 렌즈 사이의 전환**만 다룬다. 두 렌즈 사이를 매끄럽게 잇는 줌 배율 조정은 제외.
- **여러 렌즈 동시 사용**(동시 촬영·합성)
- 선택한 렌즈를 앱을 다시 켜도 기억하는 **영구 저장**
