# 카메라 미리보기 절전 (Camera Idle) — 요구사항

> 기획자 관점에서 원하는 동작을 기술한다. 코드/플랫폼 구분은 다루지 않는다.
>
> 미리보기 자체의 동작은 [카메라 미리보기 요구사항](camera-preview.md)을 참조한다. 이 문서는 그 위에 얹히는 **절전(미리보기 자동 끄기)과 재개** 동작만 다룬다.

## 개요

다이빙 중 배터리를 아끼기 위해, 카메라 화면에서 일정 시간 동안 사용이 없으면 **미리보기를 끄고 카메라를 반납**해 전력 소모를 줄인다. 이때 화면은 검은 화면으로 전환된다. 사용자가 다시 보고 싶을 때 간단한 동작으로 미리보기를 되살릴 수 있다.

## 동작

### 자동 절전 (미리보기 → 검은 화면)

- 미리보기가 켜진 상태에서 **30초** 동안 사용자 입력이 없으면, 미리보기를 끄고 **카메라를 반납**한다.
- 카메라가 반납되면 화면은 **검은 화면**이 된다. (이 동안 카메라 하드웨어는 동작하지 않아 전력을 쓰지 않는다.)

### 재개 (검은 화면 → 미리보기)

- 검은 화면(절전) 상태에서 **화면 터치**가 발생하면 미리보기를 다시 켠다.
- 미리보기가 다시 켜지면 30초 절전 타이머도 다시 시작된다.

## 비고

- 재개 수단(현재는 터치)은 [홈 요구사항](home.md)에서 다루는 다이브 하우징별 **조작 방식**과 이어진다. 하우징에 따라 다른 입력(예: 볼륨 키)으로 깨우는 것은 추후 단계에서 다룬다. 현재 단계에서는 **터치만** 재개 수단으로 둔다.
