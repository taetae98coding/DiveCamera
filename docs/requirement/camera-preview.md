# 카메라 미리보기 (Camera Preview) — 요구사항

> 기획자 관점에서 원하는 동작을 기술한다. 코드/플랫폼 구분은 다루지 않는다.
>
> 이 화면으로 진입하는 경로는 [화면 이동 요구사항](navigation.md), 진입 전 권한은 [권한 요청 요구사항](permission.md)을 참조한다.

## 개요

카메라 화면에서 사용자가 **카메라에 지금 보이는 장면을 실시간으로 확인**할 수 있게 한다. 앞으로 들어갈 촬영 기능의 토대가 되는 단계로, 현재는 **실시간 미리보기**만 제공한다. (촬영·저장·줌·전환 등은 이 문서 범위가 아니다.)

## 화면 구성

- 화면 전체 배경은 **어두운(검정) 바탕**으로 둔다.
- 화면 **가운데에 카메라 실시간 미리보기 영역**을 배치한다.
- 미리보기 영역에는 카메라가 비추는 장면이 **지연 없이 연속적으로** 표시된다.

## 동작

- 화면에 진입하면 미리보기가 **자동으로 시작**된다.
- 화면을 벗어나면(다른 화면으로 이동, 앱이 백그라운드로 전환) 미리보기는 **중지**되고, 다시 돌아오면 **재개**된다.
- 카메라 권한이 이미 허용된 상태로 이 화면에 진입한다. (권한 흐름은 권한 요구사항을 따른다.)

## 범위 밖 (이번 단계 제외)

- 사진/영상 촬영, 저장
- 카메라 전환(전/후면), 줌, 플래시
- 미리보기 위에 올라가는 컨트롤 UI (촬영 버튼 등)
