# 홈 (Home) — 요구사항

> 기획자 관점에서 원하는 동작을 기술한다. 코드/플랫폼 구분은 다루지 않는다.
>
> 이 화면으로 진입하는 경로(앱 실행 시 라우팅, 권한 화면에서의 이동)는 [화면 이동 요구사항](navigation.md)을 참조한다.

## 개요

권한이 준비된 뒤 진입하는 앱의 메인 화면이다. 앞으로 실제 기능(카메라 촬영 등)이 들어갈 자리이며, 현재 단계에서는 화면 이동이 올바르게 동작하는지 확인하기 위한 임시 화면으로 둔다.

## 화면 구성

- 화면 상단에 **제목 영역(상단 바)** 을 가진다.
- 화면 가운데에 임시로 **"Hello World!"** 문구를 표시한다. (동작 검증용이며, 이후 실제 기능으로 대체된다.)
