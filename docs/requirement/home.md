# 홈 (Home) — 요구사항

> 기획자 관점에서 원하는 동작을 기술한다. 코드/플랫폼 구분은 다루지 않는다.
>
> 이 화면으로 진입하는 경로(앱 실행 시 라우팅, 권한 화면에서의 이동)는 [화면 이동 요구사항](navigation.md)을 참조한다.

## 개요

권한이 준비된 뒤 진입하는 앱의 메인 화면이다. 사용자가 **사용할 다이브 하우징을 고르는 화면**이며, 하우징을 선택하면 그 하우징에 맞는 카메라 화면으로 이동한다.

다이브 하우징마다 물속에서 카메라를 조작하는 방식이 다르기 때문에(버튼·터치 등), 어떤 하우징을 쓰는지 먼저 선택하게 한다.

## 화면 구성

- 화면 상단에 **제목 영역(상단 바)** 을 가진다. (앱 이름: DiveCamera)
- 본문에는 선택 가능한 **다이브 하우징 목록**을 위에서 아래로 스크롤되는 카드 형태로 표시한다.
- 각 하우징 카드는 다음을 표시한다.
  - **하우징 이름** (필수)
  - **제조사** (있는 경우)
  - **대표 이미지** (있는 경우)

## 다이브 하우징 목록

현재 다음 하우징을 제공한다.

| 하우징 | 제조사 | 이미지 |
| --- | --- | --- |
| SF-PH-08 | SeaFrogs | 있음 |
| Diveroid | Diveroid | 있음 |
| 하우징 없음 | — | 없음 |

- "하우징 없음"은 별도 하우징 없이 기기만으로 촬영하는 경우를 위한 항목이다.

## 동작

- 사용자가 하우징 카드를 선택하면 **카메라 화면으로 이동**한다.
- 이때 선택한 하우징이 지원하는 **카메라 조작 방식**이 카메라 화면으로 전달된다. 하우징마다 지원하는 조작 방식이 다르다. (조작 방식 종류: 화면 터치, 볼륨(업) 키, 스와이프, 세 구획 분할 조작 등)
- 카메라 화면의 구체적 동작은 [카메라 미리보기 요구사항](camera-preview.md)을 참조한다.
