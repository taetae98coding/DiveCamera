# 권한 매니저 TC

## unitTest

- 공통 권한 매니저에 카메라, 마이크, 위치, 사진 저장 권한별 fake 매니저를 전달하면 각 권한 상태 `StateFlow`는 대응하는 fake 매니저의 권한 상태를 제공한다.
- 공통 권한 매니저의 카메라, 마이크, 위치, 사진 저장 권한 요청 함수를 호출하면 대응하는 fake 매니저의 요청 함수만 호출된다.
- 공통 권한 매니저의 앱 설정 화면 이동 함수를 호출하면 fake 앱 설정 매니저의 앱 설정 화면 이동 함수가 호출된다.
- 앱 설정 화면에서 돌아온 뒤 권한 상태를 다시 확인하는 동작은 Android/iOS 앱 생명주기와 플랫폼 notification에 의존하므로 현재 JVM 순수 로직 테스트로 직접 검증하지 않는다.

## uiTest

- 해당 없음. 권한 매니저는 UI를 직접 표시하지 않는다.
- 실제 OS 권한 상태 변경과 설정 화면 복귀 이벤트는 Robolectric `androidHostTest`에서 플랫폼별 실제 동작으로 검증하지 않는다.
