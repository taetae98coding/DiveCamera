# 테스트케이스 문서 작성 가이드

## 원칙

- TC 문서는 테스트 코드로 바로 옮길 수 있는 관찰 가능한 동작만 작성한다.
- unitTest 작성 가능한 수준만 작성한다.
- uiTest 작성 가능한 수준만 작성한다.
- E2E, 수동 확인, 배포, 기기 설정처럼 현재 테스트 소스셋에서 자동화하기 어려운 항목은 TC가 아니라 스펙 또는 검증 메모에 둔다.
- 하나의 TC는 하나의 조건과 하나의 기대 결과를 중심으로 작성한다.
- 테스트 유형 구분과 작성 형식은 [테스트케이스 작성 가이드](testcase-writing.md)를 따른다.
