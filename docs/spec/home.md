# 홈 (Home) — 스펙

> [요구사항](../requirement/home.md)과 [컨텍스트](../context/home.md)를 절충해 구현 가능한 동작을 확정한다. 코드 레벨 설명은 다루지 않는다.

## 화면 구성 (플랫폼 공통)

홈 화면은 상단 바와 다이브 하우징 목록으로 구성한다.

- **상단 바**: 화면 상단에 제목 영역을 둔다. (앱 이름: DiveCamera)
- **하우징 목록**: 본문에 다이브 하우징을 위에서 아래로 스크롤되는 카드 목록으로 표시한다.
  - 각 카드는 **이름**(필수), **제조사**(있으면), **대표 이미지**(있으면)를 표시한다.
  - 목록은 시스템 내비게이션 바 영역까지 자연스럽게 그려지도록 inset 을 처리한다.

## 제공 하우징 (플랫폼 공통)

| 하우징 | 제조사 | 이미지 |
| --- | --- | --- |
| SF-PH-08 | SeaFrogs | 있음 |
| Diveroid | Diveroid | 있음 |
| 하우징 없음 | — | 없음 |

하우징 목록은 앱에 내장된 고정 목록이다.

## 동작 (플랫폼 공통)

- 사용자가 하우징 카드를 선택하면 **카메라 화면으로 이동**한다.
- 이동 시 선택한 하우징이 지원하는 **카메라 조작 방식**(화면 터치 / 볼륨 키(업/다운) / 스와이프 / 세 구획 분할 조작 등)이 카메라 화면으로 전달된다. 하우징마다 지원 조합이 다르다.
- 이 화면으로의 진입 경로와 뒤로 가기 동작은 [화면 이동 스펙](navigation.md)을 따른다.

플랫폼 차이가 없으므로 Android/iOS 구분은 두지 않는다.
