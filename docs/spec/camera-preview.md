# 카메라 미리보기 (Camera Preview) — 스펙

> [요구사항](../requirement/camera-preview.md)과 [컨텍스트](../context/camera-preview.md)를 절충해 구현 가능한 동작을 확정한다. 코드 레벨 설명은 다루지 않는다.

## 화면 구성 (플랫폼 공통)

카메라 화면은 **검정 배경의 전체 영역**과 그 **가운데에 놓인 실시간 미리보기 영역(ViewFinder)** 으로 구성한다.

- **배경**: 화면 전체를 채우는 어두운(검정) 바탕을 둔다. 기본 컨텐츠 색은 흰색으로 한다.
- **미리보기 영역(ViewFinder)**: 화면 가운데에 배치하며, 카메라가 비추는 장면을 지연 없이 연속 표시한다.
- 이번 단계에서는 미리보기 위에 올라가는 컨트롤 UI(촬영 버튼 등)를 두지 않는다.

## 동작 (플랫폼 공통)

- **자동 시작**: 화면에 진입하면 미리보기가 자동으로 시작된다.
- **중지·재개**: 화면을 벗어나거나 앱이 백그라운드로 전환되면 미리보기가 중지되고, 화면으로 돌아오거나 앱이 다시 활성화되면 재개된다.
- **권한 전제**: 카메라 권한이 허용된 상태로 진입한다. (권한 흐름은 [권한 스펙](permission.md)을 따른다.)

## 범위 (플랫폼 공통)

- 사진/영상 촬영·저장, 카메라 전·후면 전환, 줌, 플래시, 컨트롤 UI 는 이번 스펙 범위 밖이다.

## 플랫폼별 분기

플랫폼 차이로 공통 구현이 불가능한 항목만 정리한다. (근거는 [컨텍스트 문서](../context/camera-preview.md) 참조)

배경·정렬·검정 바탕은 공통 구현하며, **미리보기 영역(ViewFinder)의 카메라 연동만** 분기한다. 공통 구현이 불가능한 이유: iOS 에는 Android 의 CameraX 에 대응하는 고수준 1st-party 카메라 라이브러리가 없어, 미리보기를 만드는 방식과 수명주기 관리 방식이 플랫폼마다 다르다.

### Android

- 공식 라이브러리 **CameraX** 로 미리보기를 구성한다. Compose 어댑터의 카메라 뷰파인더 컴포저블이 카메라 프리뷰 스트림을 받아 화면 가운데에 표시한다.
- 화면 수명주기에 **자동으로 연동**되어, 진입 시 미리보기가 시작되고 이탈·백그라운드 시 자동 중지, 복귀 시 재개된다. (별도 수동 제어 불필요)

### iOS

- 공식 프레임워크 **AVFoundation** 으로 미리보기를 구성한다. 카메라 세션의 실시간 프리뷰를 네이티브 뷰에 담아 Compose 화면 가운데에 임베드한다.
- 수명주기 자동 관리가 없으므로 **직접 제어**한다. 화면 진입·앱 활성 시 세션을 시작하고, 화면 이탈·백그라운드 시 세션을 중지한다. (사용자 체감 동작은 Android 와 동일)
- 세션 시작은 화면 응답성을 위해 메인 스레드를 막지 않도록 처리한다.
- **검증 제약**: iOS 시뮬레이터에는 카메라가 없어 미리보기는 **실기기에서만** 확인된다.
