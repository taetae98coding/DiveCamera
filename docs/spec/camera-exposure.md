# 노출 정보 표시 (Camera Exposure) — 스펙

> [요구사항](../requirement/camera-exposure.md)과 [컨텍스트](../context/camera-exposure.md)를 절충해 구현 가능한 동작을 확정한다. 코드 레벨 설명은 다루지 않는다.

## 화면 구성 (플랫폼 공통)

- 미리보기 위 **화면 상단**에 촬영 정보 영역을 둔다. 시스템 상태바 영역과 겹치지 않게 배치한다.
- **ISO · 조리개(F값) · 셔터스피드 · 노출 보정값(EV) · 렌즈 초점거리**를 한 줄에 나란히 표시한다.

## 동작 (플랫폼 공통)

- **실시간 갱신**: 카메라 미리보기가 켜져 있는 동안, 카메라가 노출을 조절할 때마다 값이 들어오는 스트림 그대로 갱신된다. (별도 스로틀 없음)
- **노출 보정값(EV)**: 현재 카메라에 **설정된 보정값을 읽어 표시**한다. 보정값은 [수동 노출 제어](camera-exposure-control.md)의 P 모드에서 바꿀 수 있으며, 바꾸기 전 기본값은 `EV 0.0` 이다. (M 모드에서는 같은 자리에 노출 측광계를 표시 — 같은 문서 참조)
- **절전 연동**: 절전으로 미리보기가 꺼지면(검은 화면) 촬영 정보 영역도 표시하지 않는다. 미리보기가 재개되면 다시 표시한다. (절전 동작은 [카메라 절전 스펙](camera-idle.md))

## 표기 형식 (플랫폼 공통)

값이 없거나(null) 유효하지 않으면(예: 셔터스피드·초점거리가 0 이하) 해당 항목은 `--` 로 표시한다. 그 외에는 전문 카메라(미러리스) 관례를 따른다.

- **ISO**: `ISO ` 뒤에 정수. (예: `ISO 100`, `ISO 6400`)
- **조리개(F값)**: 앞에 `F`.
  - 10 미만은 소수점 첫째 자리까지. (예: `F1.8`, `F4.0`, `F5.6`, `F8.0`)
  - 10 이상은 정수. (예: `F11`, `F16`, `F22`)
- **셔터스피드**:
  - **0.3초보다 빠르면** 분수 표기. (예: `1/125`, `1/4000`)
  - **0.3초 이상이면** 초 단위 표기로, 소수점 자리를 `"` 로 나타낸다. (예: `0"5` = 0.5초, `1"3` = 1.3초, `4"` = 4초, `30"` = 30초)
- **노출 보정값(EV)**: 앞에 `EV `, 뒤에 부호와 소수점 첫째 자리. (예: `EV +0.3`, `EV 0.0`, `EV -1.0`) M 모드에서 같은 자리에 표시되는 노출 측광계도 같은 형식을 따른다. ([수동 노출 제어](camera-exposure-control.md))
- **렌즈 초점거리**: 풀프레임(35mm) 환산 초점거리를 정수로, 뒤에 `mm`. (예: `13mm`, `26mm`, `77mm`)

## 범위 (플랫폼 공통)

- 노출 값·노출 보정값의 **수동 조작**(직접 변경), 측광 모드, 위에 나열한 것 이외의 촬영 정보(WB 등)는 이번 스펙 범위 밖이다.
- 노출 보정값은 **현재 설정값 표시(읽기)** 까지만 포함한다.

---

## 플랫폼별 분기

플랫폼 차이로 공통 구현이 불가능한 항목만 정리한다. (근거는 [컨텍스트 문서](../context/camera-exposure.md) 참조)

상단 촬영 정보 UI·표기 형식·절전 연동은 공통 구현하며, **값을 카메라에서 읽어 오는 방식**만 분기한다. 표시 값과 단위(렌즈 초점거리 포함)는 모두 공통이다.

- **값 취득 방식**이 분기되는 이유: 노출/촬영 값은 플랫폼별로 다른 네이티브 카메라 세션(미리보기)에서만 얻을 수 있기 때문이다.
- **렌즈 초점거리**는 표시 값(풀프레임 35mm 환산 mm)은 공통이되, 환산에 쓰는 입력값을 얻는 경로만 다르다. (근거는 [컨텍스트 5번](../context/camera-exposure.md)) 노출 값과 달리 렌즈가 바뀌지 않는 한 변하지 않으므로 **노출과 분리된 별도 상태**에서 바인딩 시 한 번 계산한다.

### Android

- 미리보기 카메라 세션에서 프레임마다 ISO·노출 시간·조리개·노출 보정값을 읽어 상단 표시에 전달한다. (취득 경로·API 근거는 [컨텍스트](../context/camera-exposure.md))
- **조리개**: 기기가 가변 조리개를 지원하면 현재 F값이 실시간으로 갱신되고, 고정 조리개 기기에서는 고정된 F값이 표시된다.
- **노출 보정값(EV)**: 기기가 보고하는 보정값을 EV 단위로 환산해 표시한다. (환산에 필요한 보정 스텝은 미리보기 시작 시 한 번 확보한다.)
- **렌즈 초점거리**: 실제 초점거리와 센서 크기로 풀프레임 환산값을 구해 표시한다. (미리보기 시작 시 한 번 — 환산 기준은 iOS 와 동일하다.)
- 일부 기기(하드웨어 지원 레벨이 낮은 경우)는 ISO·노출 시간 등이 제공되지 않을 수 있으며, 이때는 `--` 로 표시된다.

### iOS

- 미리보기 카메라 세션의 프레임마다 ISO·노출 시간·조리개·노출 보정값을 읽어 상단 표시에 전달한다. (취득 경로·API 근거는 [컨텍스트](../context/camera-exposure.md))
- **조리개**: iPhone 은 가변 조리개 하드웨어가 없어 F값이 **변하지 않는 고정값**으로 표시된다. (사용자 체감상 ISO·셔터만 실시간으로 움직인다.)
- **노출 보정값(EV)**: 카메라가 보고하는 보정값을 EV 단위로 그대로 읽는다. 바꾸기 전 기본값은 `EV 0.0` 이다. (설정은 [수동 노출 제어](camera-exposure-control.md))
- **렌즈 초점거리**: iOS 는 mm 초점거리를 직접 주지 않으므로, 카메라가 주는 화각에서 풀프레임 환산값을 계산해 표시한다. (미리보기 시작 시 한 번 — 환산 기준은 Android 와 동일하다.)
- **검증 제약**: iOS 시뮬레이터에는 카메라가 없어 촬영 값도 **실기기에서만** 확인된다. (미리보기와 동일)
