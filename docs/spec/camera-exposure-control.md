# 수동 노출 제어 (Camera Exposure Control) — 스펙

> [요구사항](../requirement/camera-exposure-control.md)과 [컨텍스트](../context/camera-exposure-control.md)를 절충해 구현 가능한 동작을 확정한다. 코드 레벨 설명은 다루지 않는다.

## 화면 구성 (플랫폼 공통)

- 상단 촬영 정보 영역(노출 정보 표시)을 누르면 **설정 오버레이**가 열린다. 미리보기 위에 어두운 막(scrim)과 함께 패널로 표시된다.
- 오버레이는 두 단계로 동작한다.
  - **1단계 — 설정 항목 리스트**: 설정할 수 있는 항목을 세로로 나열한다. 각 행은 **항목 이름 + 현재 값**을 보여 준다. 맨 아래에는 오버레이를 닫는 행이 있다.
  - **2단계 — 값 선택 리스트**: 한 항목을 누르면 그 항목이 가질 수 있는 값들이 리스트로 펼쳐진다. 리스트는 **현재 값이 보이도록 그 위치로 스크롤된 상태**로 열리고, **현재 값에는 체크 표시**가 붙는다. 값을 누르면 적용되고 1단계로 돌아간다.
- 1단계 항목 순서
  1. **Mode** — 현재 모드(Program / Manual)를 보여 주고, 누르면 모드 선택 리스트를 연다. 모드 선택 리스트에는 `Program`·`Manual` 두 모드가 나열된다. 기기가 Manual 을 지원하지 않으면 Mode 항목은 **비활성(회색)** 으로 보여 누를 수 없다(Program 으로 고정).
  2. 현재 모드에 따른 노출 항목
     - **P 모드**: `EV`
     - **Manual 모드**: `ISO`, `셔터스피드`, `조리개`
- 한 항목의 **선택 가능한 값이 2개 미만**이면(바꿀 게 없으면) 그 1단계 항목은 **비활성(회색)** 으로 보여 누를 수 없다. (예: 고정 조리개 기기·iOS 의 조리개, 노출 보정을 지원하지 않는 기기의 EV)
- (향후 이 리스트 아래로 HDR·렌즈 선택 등 다른 설정 항목이 같은 구조로 추가된다. 이번 스펙은 노출 항목까지만 포함한다.)
- 막을 누르거나 닫기 행을 누르면 오버레이가 닫히고 미리보기로 돌아간다.

## 동작 (플랫폼 공통)

- 모드를 바꾸면 1단계 리스트의 노출 항목이 모드에 맞게 즉시 바뀐다. (P → EV / Manual → ISO·셔터·조리개)
- 값을 선택하면 카메라에 즉시 반영되고, 상단 촬영 정보 표시도 함께 갱신된다. (표시 갱신은 [노출 정보 표시 스펙](camera-exposure.md)의 실시간 읽기 경로를 그대로 탄다.)
- **P 모드의 EV**: 선택한 보정값으로 전체 밝기가 오르내린다. 노출 3요소는 카메라가 맞춘다.
- **Manual 모드**: 선택한 ISO·셔터스피드가 그대로 적용되고 자동 노출은 멈춘다. Manual 로 처음 들어갈 때는 **직전 자동 노출이 측정하던 현재 값**을 시작값으로 삼아 화면 밝기가 튀지 않게 한다.
- **초기 모드는 P**다. 한 번 바꾼 설정은 카메라가 켜져 있는 동안만 유지되고, 앱을 다시 켜면 P 로 초기화된다.

## 상단 EV 표시 (모드별)

상단 촬영 정보 영역의 EV 값은 모드에 따라 의미가 다르다.

- **P 모드 (플랫폼 공통)**: 사용자가 건 **노출 보정값**을 표시한다. (오버레이에서 설정)
- **M 모드**: **노출 측광계**(현재 설정이 측광된 적정 노출에서 벗어난 정도, EV 단위)를 읽기 전용으로 표시한다. 장면 밝기에 따라 수시로 갱신된다.
  - **iOS**: 측광 오프셋을 실시간으로 표시한다.
  - **Android**: 측광 오프셋을 주는 직접 API 가 없어 이번 단계에서는 `--` 로 표시한다. (프레임 밝기 분석 기반 구현은 범위 밖)
- 표기 형식은 [노출 정보 표시 스펙](camera-exposure.md)의 EV 표기(`EV +0.7` 등)를 따른다. M 모드에서 EV 는 오버레이의 설정 항목이 아니다(표시 전용).

## 값 표기 (플랫폼 공통)

- 각 항목의 현재 값·선택지 표기는 [노출 정보 표시 스펙](camera-exposure.md)의 표기 형식(ISO·F값·셔터스피드·EV)을 그대로 따른다.
- 모드 표기는 `Program` / `Manual` 로 한다.
- **Manual 모드**에서 표시하는 현재 ISO·셔터스피드·조리개 값은 기기가 실제 적용·보고한 값을 **선택 가능한 값 목록 중 가장 가까운 값으로 맞춰** 표기한다. 하드웨어가 표준 단계와 미세하게 다른 값을 보고해도(예: ISO 150 을 요청해도 센서 게인 양자화로 149 가 보고됨) 표준 단계로 보이게 하기 위함이다. (P 모드에서는 카메라가 자동으로 정한 값을 기기가 보고한 그대로 표기한다.)

## 선택 가능한 값 목록 (플랫폼 공통)

기기가 알려 주는 지원 범위 안에서 다음 기준으로 목록을 만든다. 목록은 미리보기 시작(바인딩) 시점에 한 번 정해진다.

- **ISO**: 표준 1/3스톱 단계(50, 100, 150, 200, 250, 320, 400, …, 6400) 중 지원 범위에 드는 값.
- **셔터스피드**: 표준 단계(1/8000, 1/6400, …, 1/30, …, 1", 2", 4", …, 30") 중 지원 범위에 드는 값.
- **조리개**: 기기가 제공하는 사용 가능한 F값 목록 그대로. (Android 는 기기가 알려 주는 조리개 목록 — 대부분의 기기는 고정 조리개라 1개. iOS 는 현재 고정 F값 1개.)
- **EV**: 지원 범위를 기기 보정 스텝 단위로 나눈 값. (예: 1/3 스텝이면 …, -1.0, -0.7, -0.3, 0.0, +0.3, …)
- 선택 가능한 값이 2개 미만인 항목은 위처럼 비활성이므로, 값 선택 리스트는 선택지가 2개 이상일 때만 열린다.

## 절전과의 관계 (플랫폼 공통)

- 절전으로 미리보기가 꺼지면 상단 정보·오버레이 모두 표시되지 않는다. (미리보기가 살아 있는 동안에만 설정 가능)
- 오버레이를 여는 동작과 오버레이 안의 모든 조작(탭·스크롤 등)은 사용자 활동으로 간주해 **절전 타이머를 연장**한다. 따라서 오버레이를 띄워 둔 채 설정을 다루는 동안에는 절전으로 미리보기가 꺼지지 않는다.

## 범위 (플랫폼 공통)

- P/Manual 외 추가 모드(Tv/Av), 측광 모드, 화이트밸런스·초점 수동 제어, 노출 항목 외 설정(HDR·렌즈 선택 등 실제 항목), 영구 저장은 이번 스펙 범위 밖이다.

## 플랫폼별 분기

설정 오버레이 UI·2단계 리스트·표기·절전 연동은 공통 구현하며, **카메라에 값을 적용하는 경로**와 **선택 가능한 값 범위를 조회하는 경로**만 분기한다. (근거는 [컨텍스트 문서](../context/camera-exposure-control.md))

### Android

- **모드**: 자동 노출을 켜서(P)/꺼서(Manual) 전환한다. Manual 의 ISO·셔터·조리개와 P 의 EV 보정은 카메라 세션에 직접 적용한다. (적용 경로·API 근거는 [컨텍스트](../context/camera-exposure-control.md))
- **조리개**: 기기가 알려 주는 사용 가능한 조리개 값을 그대로 목록으로 쓰고, 선택값을 적용한다. (대부분의 기기는 고정 조리개라 값이 1개다.)
- **EV**: 보정 인덱스 범위·스텝으로 값 목록을 만들고, 선택값을 적용한다.

### iOS

- **모드**: 연속 자동 노출(P)과 수동(Manual)을 전환한다. Manual 의 ISO·셔터는 **한 번에 함께** 적용되므로, 한 값만 바꿔도 다른 값의 현재치를 함께 넘긴다. EV 는 노출 보정값(EV 단위)을 그대로 적용한다. (적용 경로·API 근거는 [컨텍스트](../context/camera-exposure-control.md))
- **조리개**: iPhone 은 조리개를 설정하는 수단이 없다. 값 목록이 고정 F값 1개뿐이라 조리개 항목은 비활성으로 보이며, 설정해도 바뀌지 않는다(no-op).
- **EV**: 지원 범위(EV 단위)를 보정 스텝(1/3 EV)으로 나눠 값 목록을 만든다.

### 검증 제약

- 실제 지원 범위·가변 조리개 여부·Manual 지원 여부는 기기마다 달라 **실기기**에서 확인한다. iOS 시뮬레이터·일부 Android 에뮬레이터는 카메라/수동 제어가 없어 값 목록이 비거나 설정이 반영되지 않을 수 있다.
