# 권한 화면 Context

## UI 구성

- 권한 화면은 `PermissionManager`의 네 가지 권한 `StateFlow`를 Compose state로 수집해 표시한다.
- 허용된 권한 항목은 클릭 가능한 Card를 사용하지 않는다.
- 허용되지 않은 권한 항목은 클릭 가능한 Card를 사용하고 대응하는 권한 요청 함수를 호출한다.
- 권한 항목의 체크박스는 상태 표시용으로만 사용하며 직접 토글하지 않는다.
- 권한 화면의 비디오 관련 설명 문구는 이후 비디오 캡처 기능에서 같은 카메라, 마이크, 위치, 저장 권한을 사용할 것을 전제로 유지한다.
- 현재 사진 캡처 구현은 비디오 캡처 모드 제공 여부와 독립적으로 권한 화면 문구를 표시한다.

## Navigation 경계

- 권한 화면 Composable은 `NavBackStack`을 직접 받지 않는다.
- 권한 화면 EntryProvider는 모든 권한이 허용된 뒤 카메라 화면으로 이동할 때 back stack을 비우고 카메라 destination을 추가한다.
- 권한 화면 EntryProvider가 back stack을 교체하므로 카메라 화면에서 뒤로 이동해 권한 화면으로 돌아가는 흐름은 기본 제공하지 않는다.
